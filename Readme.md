# Repository for ``Tags for DAGs: Graph Refinement with Meta-Informed Relations``

This is the reposity for the corresponding paper submitted to TMLR.

We also use some code from the code repository on typing causality (https://github.com/ServiceNow/typed-dag), licensed under the Apache License 2.0.

We provide a docker container for the easy setup and replication of experiments. The Dockerfile can be found at `.docker/Dockerfile`.  
Optionally, we provide a devcontainer at `.devcontainer/devcontainer.json` for connecting with Visual Studio Code.

### Main Evaluation

Data for the main evaluation can be generation with a single call to `data/bnlearn_data.py`.

The main evaluation can be run by executing `run_eval.sh`.
Results are stored under the `results/` folder. The resulting tables from the paper can then be generated by running `results_eval.py` to directly generate latex code. (Set `paper_table` to switch between different results.)
When `paper_table` is set to 0, this also computes the differences as shown in the one-at-a-time sensitivity analysis and stores these within the `_configs` subfolder.

### Ablation Experiments

Ablation experiments regarding graph faults and tag fauls can be run by executing `run_ablation.sh`.
The corresponding plots and tables used in the paper can then be generated by running `ablation_collect.py` and `ablation_collect_tags.py`.

The main evaluation with added noise can be run using `run_eval_noise.sh`.
In order to get the comparison between the standard and the noisy main evaluation, both need to have been run and results need to be compiled using `results_eval.py`. For this, simply set `paper_table` to 3 and run `results_eval.py` for both `main_evaluation` and `noise_evaluation` with this value (this will generate files a subfolders of the respective evaluation results folder called `_results_tables`). The table from the paper can be created with `util_combine_tables.py` afterwards.

Similarly, the main evaluation with a reduced number of tags can be run using `run_reduced_tags.sh`.
Here, results can be collected using `results_eval_reduced_tags.py` which creates the table shown in the paper.

### Homogeneity Analysis

The homogeneity analysis of ground truth graphs and the plotting of results is integrated with a single call to `homogenity_eval.py`.

For the shared tag analysis, all files can be found under the folder `shared_tag_analysis`.
`tagpairs.txt` can be produced using `homogenity_eval.py` without limiting max_tag_pairs (e.g., simply set to 1000). From this, `extract_tagpairs.py` produces `tagpairs.csv` and, then, `find_shared_tagpairs.csv` produces `shared_tagpairs.csv`, which contains the results discussed in the paper.

**General Information:** The internal method called `tag_pc_0_on_ges` contains the term `pc' for historic reasons but does not utilize PC results in any way. The approach is applied purely to the resulting CPDAG of GES.


### Further Experiments

We conduct several additional experiments that check for different aspects. For simplicity, we simply numbered these additional experiments:

- **E1:** Run `E1_tag_consistency.py` for the experiment on tag consistency (correlation between tag pair direction of directed and undirected edges).
- **E2:** Run `E2_loocv.py` for the leave-one-out cross validation using the results of our main evaluation (run that first if not already done).
- **E3:** Run `E3_different_thresholds.sh` and then `E3_different_thresholds.py` for an experiment checking different thresholds for directing edges (compared to leaving more edges undirected).
- **E4:** Run `E4_bad_directs.py` to investigate bad edge directions due to tagging based on the results of our main evaluation (run that first if not already done).
- **E5:** Run `E5_run_laplace.sh` and then `E5_laplace_eval.py` for a variant of the main evaluation that uses laplace correction for evidence used in tagging.
- **E6:** Run `E6_llm_model_versions.sh` and then `E6_llm_model_versions.py` to compare different LLM versions using well performing parameter configurations from the main evaluation.
- **E7:** Run `E7_llm_prompt_versions.sh` and then `E7_llm_prompt_versions.py` to compare different results on the datasets also used in our main evaluation. Here, different prompts for getting the tags from LLMs have been used.
