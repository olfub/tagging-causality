2.  The application calls the GDI (Graphics Device Interface).
3.  The system spools the job (creates an EMF or RAW file).
4.  While this initial handoff and processing occur, the user interface is often blocked, displaying the hourglass cursor.

*   The more complex the data generation is (e.g., high-resolution graphics, complex formatting), the longer the application holds the system focus.
